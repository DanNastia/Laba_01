## Функционал

### Калькулятор
Калькулятор работает с:
- Целыми и вещественными числами
- Стандартными бинарными арифметическими операциями: `+`, `-`, `*`, `/`
- Унарными операторами `+` и `-` перед числами
- Обработка круглых скобок `()` для изменения приоритета

### Конвертер
Конвертер поддерживает преобразование следующих групп:
- **Длина:** миллиметры (`mm`), сантиметры (`cm`), метры (`m`), километры (`km`).
- **Масса:** граммы (`g`), килограммы (`kg`).
- **Температура:** градусы Цельсия (`c`), Фаренгейта (`f`), Кельвины (`k`).

*Примечание: регистр единиц измерения не учитывается. Конвертация между разными физическими группами или передача температуры ниже абсолютного нуля запрещены.*

## Установка и запуск

Для работы программы требуется Python версии `>=3.12`.

1. Клонируйте репозиторий и перейдите в папку проекта:

   git clone https://github.com/DanNastia/Laba_01.git

2. Настройте виртуальное окружение и установите проект в режиме редактирования:

   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -e .[dev]

3. Запуск калькулятора для вычисления математического выражения:

   python -m toolkit calc "Выражение"

4. Запуск конвертера:

   python -m toolkit convert число --from группа_1 --to группа_2

5. Просмотр справочной информации:

   python -m toolkit --help
